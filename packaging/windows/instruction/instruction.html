🐧 Penguin Detector

Інструкція для підрахунку пінгвінів на аерофотознімках. Програма працює на вашому комп'ютері без інтернету: знімки нікуди не надсилаються.

Windows 10 або 1164-бітна
16 GB пам'ятімінімум 8 GB
6 GB на дискувільного місця
Без інтернетуне потрібен

1Перший раз: розпакувати програму

Це потрібно зробити лише один раз. Далі програма просто запускається (крок 2).

  1. Скопіюйте файл PenguinDetector-windows.zip на комп'ютер (з флешки або завантажте).
  2. Клацніть по файлу правою кнопкою миші → Властивості. Внизу вікна поставте галочку Розблокувати → OK.
    Якщо такої галочки немає — нічого страшного, переходьте далі.
  3. Знову клацніть правою кнопкою по файлу → Видобути все…
  4. У полі шляху зітріть те, що там написано, і впишіть C:\ → Видобути.
    З'явиться папка C:\PenguinDetector.

⏳ Розпакування триває 5–15 хвилин — у програмі багато файлів. Дочекайтеся, поки вікно копіювання зникне.

Розпаковуйте саме в C:\, а не в «Завантаження» чи на робочий стіл: у Windows є обмеження на довжину шляху до файлів, і з глибоких папок програма може не запуститися.

2Запуск програми

  1. Відкрийте папку C:\PenguinDetector.
  2. Двічі клацніть файл START.bat (може показуватися просто як START).
  3. Якщо з'явиться синє вікно «Windows захистив ваш комп'ютер» — натисніть Докладніше → Усе одно запустити. Це стандартне попередження для програм, завантажених не з магазину Microsoft.
  4. Відкриється чорне вікно. Приблизно через 30–60 секунд у браузері сама відкриється програма.
Запуск Penguin Detector... Зачекайте, будь ласка (до хвилини). ============================================================ Penguin Detector працює. Якщо браузер не відкрився сам, відкрийте адресу: http://localhost:8501 НЕ ЗАКРИВАЙТЕ це вікно, поки працюєте з програмою. Щоб завершити роботу, просто закрийте це вікно. ============================================================

Не закривайте чорне вікно, поки користуєтеся програмою — це і є сама програма. Браузер лише показує її.

💡 Ярлик на робочий стіл: клацніть правою кнопкою по START.bat → Показати додаткові параметри → Надіслати → Робочий стіл (створити ярлик). Далі запускайте програму з робочого столу.

3Підрахунок пінгвінів

  1. Натисніть Browse files і виберіть знімок — або просто перетягніть файл у це поле.
    Підходять формати JPG, PNG, TIFF (зокрема ортомозаїки GeoTIFF), розміром до 5 GB.
  2. Натисніть синю кнопку 🔍 Detect Penguins.

Почнеться обробка. Знімок розрізається на частини («тайли»), і програма перевіряє кожну. Над смужкою видно, скільки частин оброблено і скільки часу залишилось.

Поки йде обробка, не закривайте сторінку і не натискайте нічого на ній (зокрема хрестик біля назви файлу) — інакше обробку доведеться починати спочатку.

ЗнімокСкільки чекати (приблизно)
Одне фото з дрона (20 мегапікселів)до 1 хвилини
Велика ортомозаїка (200–400 мегапікселів)10–30 хвилин

З моделлю RF-DETR обробка зазвичай у кілька разів довша. Можна тим часом займатися іншими справами — просто не закривайте браузер і чорне вікно.

4Налаштування (зліва)

НалаштуванняЩо означає
Model
(модель)		 YOLOv11 — Augmented — рекомендована: найточніша загальна кількість, працює швидко.
RF-DETR — Baseline — знаходить майже всіх пінгвінів, але частіше помилково позначає камені чи тіні. Повільніша.
Confidence threshold
(поріг впевненості)		 Наскільки модель має бути впевнена, щоб порахувати об'єкт пінгвіном. За замовчуванням 0.25 — залиште так.
Більше значення → менше помилкових позначок, але частину пінгвінів можна пропустити.

Після обробки повзунок можна рухати вправо — результат оновиться одразу, без повторної обробки. Щоб побачити результат з меншим порогом, ніж був під час обробки, натисніть Detect Penguins ще раз.

5Результат

ПолеЩо означає
Penguins detectedКількість знайдених пінгвінів — головний результат.
Avg / Max confidenceСередня й найвища впевненість моделі (у відсотках).
Processing timeСкільки тривала обробка.

Модель може помилятися: пропустити пінгвіна, якого закриває інший, або сплутати пінгвіна з каменем. Для точного підрахунку перевірте результат у Fiji / ImageJ (крок 6).

6Збереження результатів

Під зображеннями є три кнопки (Export results). Файли зберігаються в папку Завантаження (Downloads).

КнопкаЩо зберігає
RoiSet.zip — ImageJРамки всіх пінгвінів для Fiji / ImageJ, де їх можна перевірити й виправити вручну.
У Fiji: відкрийте знімок → Analyze → Tools → ROI Manager → More → Open… → виберіть RoiSet.zip.
Image (PNG)Картинка зі знайденими пінгвінами (зменшена копія знімка) — для звіту чи швидкого перегляду.
Label Studio JSONРозмітка для програми Label Studio (Tasks → Import). Потрібна, лише якщо ви з нею працюєте.

Збережіть потрібні файли до того, як завантажите наступний знімок або закриєте програму: результати не зберігаються автоматично.

7Завершення роботи

Закрийте вкладку браузера і чорне вікно. Наступного разу — знову двічі клацніть START.bat (крок 2).
